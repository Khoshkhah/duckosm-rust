duckOSM boundary tool

Find the boundary of an area and save it as a duckOSM boundary file (the format of duckosm boundary). The file works in duckOSM in the browser, in duckosm-rust build --boundary and in a duckOSM config. The tool also gives the smallest Geofabrik extract that covers the area.
