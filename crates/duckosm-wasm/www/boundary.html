duckOSM boundary tool

Make the area that duckOSM builds. Save it as a boundary file (the format of duckosm boundary), or use it in duckOSM in the browser.

then click the map

Search: Nominatim, data © OpenStreetMap contributors.

Rectangle and circle: drag on the map. Polygon: click each vertex, then click the first vertex or push Enter. Edit: select a shape, then drag a vertex or the midpoint of a side. Escape stops a shape. Shapes that overlap become one polygon. The drawing needs a mouse, a pen or a finger; the search and the file work with the keyboard.
